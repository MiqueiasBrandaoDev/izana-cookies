# Assets

Tudo aqui é JPG de alta qualidade. Os PNG originais (148 MB) ficaram de fora do
repositório; estes 13 MB são o que a skill precisa para trabalhar.

## `referencias/`

**As fotos reais do produto.** São a base de tudo: vão em `image[]` na chamada de geração
para o modelo reconstruir o cookie certo. Sem elas o cookie sai genérico.

| Arquivo | O que é |
|---------|---------|
| `foto-real-cookie-nutella.jpg` | foto real, cookie de chocolate com creme por cima |
| `foto-real-cookie-creme-branco.jpg` | frame real, cookie claro aberto com recheio branco |
| `ref-banner-berry-dubai.jpg` | o banner de terceiro que deu a estrutura da peça |
| `ref-berry-dubai-transcricao.json` | transcrição do reel de onde saiu a referência |

## `produto/`

18 fotos de produto geradas e aprovadas. Servem como referência nas gerações seguintes,
e várias já servem como arte final.

Destaques:

| Arquivo | Uso |
|---------|-----|
| `f_hero_vertical.jpg` | grupo de sabores, espaço em cima para tipografia — o herói dos banners |
| `f_hero_unico.jpg` | um cookie inteiro, cobertura escorrendo |
| `f_fileira.jpg` | quatro sabores lado a lado, para faixa inferior |
| `f_pilha.jpg` | pilha vertical |
| `f_topo.jpg` | vista de cima com seis cookies |
| `angulo_2_partido.jpg` | **o único cookie aberto aprovado**: duas metades com o fio de chocolate esticando |
| `s2_hero.jpg`, `s2_partido.jpg` | o sabor de creme branco |

Os arquivos `hero_recheio_*` e `multi_*` são de uma rodada reprovada por textura seca.
Estão aqui como histórico; prefira os `f_*`.

## `banners/`

Cada pasta registra uma rodada, e as reprovadas existem de propósito — são o registro
de um erro que não deve voltar.

| Pasta | O que registra |
|-------|----------------|
| `v1-reprovados/` | marca de terceiros, escassez, "feito na hora", sabor único |
| `v2-reprovados/` | cookies abertos, secos e esfarelados |
| `v3-texto-aprovado/` | texto certo, mas frases de impacto ainda forçadas |
| `v4-fontes/` | **as 10 opções de tipografia da marca, aguardando escolha da Izana**. Veja `_fontes_v5.jpg` para comparar só a tipografia e `_todos_v5.jpg` para ver as peças inteiras |
